# Лабораторна робота: Проектування оптимальних цифрових фільтрів Вінера в MATLAB

## Мета роботи  
Ознайомитися з методами проектування оптимальних цифрових фільтрів Вінера та реалізувати їх у середовищі MATLAB для обробки сигналів.

## Теоретична частина  
Цифрові фільтри Вінера призначені для мінімізації середньоквадратичної помилки між вихідним сигналом системи і бажаним сигналом. Вони широко застосовуються для відновлення сигналів, згладжування шуму та адаптивної обробки.

## Завдання  
1. Розробити алгоритм проектування оптимального цифрового фільтра Вінера в MATLAB.  
2. Написати програму, яка реалізує проектування фільтра на основі заданих вхідних даних (сигналів та шуму).  
3. Провести тестування фільтра на прикладі синтетичних сигналів з шумом.  
4. Побудувати графіки вхідного сигналу, зашумленого сигналу та відфільтрованого сигналу.

## Короткий опис реалізації  
- Визначення параметрів вхідного сигналу та шуму.  
- Формування автокореляційної та крос-кореляційної матриці.  
- Розв’язання рівнянь Вінера для знаходження коефіцієнтів фільтра.  
- Застосування фільтра до вхідного сигналу.  
- Візуалізація результатів.

## Використання MATLAB  
- Реалізація алгоритму за допомогою базових функцій MATLAB.  
- Візуалізація графіків за допомогою `plot`.  
- Можливе застосування функцій для роботи з кореляціями (`xcorr`, `toeplitz`).
