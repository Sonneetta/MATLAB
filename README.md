# Лабораторна робота №4  
**Різницеві моделі цифрових пристроїв.  
Моделювання динамічного нейрона. Графічне дослідження моделі**

## Мета роботи
- Провести моделювання цифрових пристроїв, описаних різницевими рівняннями.
- Ознайомитися з підходами до графічного дослідження дисипативних динамічних систем.
- Дослідити моделі нейронів, що демонструють хаотичну поведінку.
- Ознайомитися з підсистемою **Neural Networks** у MATLAB.

## Завдання
1. **Розробити алгоритм** та написати програму в **MATLAB** для розв'язання рівняння: x(n+1) = 4 * x(n) * (1 + x(n))
2. **Побудувати діаграму Ламерея (Lamerey)**, що дозволяє візуалізувати зміну траєкторій залежно від параметрів і початкових умов.
3. **Знайти стійкі та нестійкі точки** системи.
4. **Ознайомитися з основними типами нейронів** у середовищі MATLAB, зокрема у підсистемі **Neural Networks**.

## Реалізація
Програмна реалізація передбачає:
- Ітеративне обчислення значень `x(n)` на основі заданого рівняння.
- Побудову графіків залежності `x(n)` від `n`.
- Візуалізацію фазового простору та діаграму Ламерея.
- Використання пакету **Neural Networks Toolbox** для створення та дослідження моделей штучних нейронів.
