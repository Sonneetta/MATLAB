# Лабораторна робота №5  
**Реконструкція математичної моделі по часовому ряді**

## Мета роботи  
Ознайомитися з методом реконструкції математичної моделі по часовому ряді на прикладі системи Лоренца.

## Завдання  
1. Розробити алгоритм та написати програму в MATLAB для розв'язання рівняння Лоренца з хаотичним аттрактором.  
2. Використовуючи змінну \( x(t) \) системи Лоренца, обчислити кореляційний інтеграл.  
3. Графічним способом обчислити кореляційну розмірність аттрактору.

## Короткий опис  
- Модель Лоренца — класична система диференціальних рівнянь, яка демонструє хаотичну поведінку при певних параметрах.  
- Кореляційний інтеграл використовується для оцінки фрактальної розмірності аттрактору на основі часового ряду.  
- Візуалізація та аналіз дають змогу краще зрозуміти структуру хаотичного аттрактору.

## Приклад використання MATLAB  
- Розв'язання системи Лоренца за допомогою вбудованих засобів MATLAB (наприклад, `ode45`).  
- Обчислення кореляційного інтегралу за допомогою алгоритмів аналізу часових рядів.  
- Побудова графіків для оцінки кореляційної розмірності.
