# Лабораторна робота №1

## Тема
Ознайомлення з пакетом MATLAB. Базові конструкції мови програмування.

## Мета
- Ознайомлення з операційним середовищем MATLAB.
- Використання командного вікна, редактора М-файлів та робочої області.
- Засвоєння базових команд MATLAB та навичок програмування.

## Завдання
1. Операції з векторами: виконання обчислень із заданими векторами `A` та `B`.
2. Елементне піднесення до степеня та ділення.
3. Порівняння масивів за умовою `A < B`.
4. Створення та заповнення вектора `x` за допомогою циклу `for`.
5. Генерація магічного квадрата за допомогою функції `magic(4)`.
6. Створення та виклик користувацької функції в М-файлі:
    ```matlab
    function C = myfile(a, b)
    C = sqrt((a.^2) + (b.^2))
    ```
7. Генерація тривимірного масиву випадкових чисел з нормальним розподілом.
8. Інтерполяція значень синусоїди з побудовою графіка за допомогою `spline()`.

## Використані інструменти
- MATLAB: командне вікно, редактор скриптів, робоче середовище.
- Графічна побудова з використанням функції `plot()`.

## Результат
Одержано базові навички роботи в середовищі MATLAB, виконано типові операції над масивами, реалізовано прості алгоритми та створено власні функції.
