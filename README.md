# Лабораторна робота №2  
**Simulink: моделювання динамічних систем в середовищі Simulink**

## Мета
- Ознайомлення з графічним інтерфейсом Simulink.
- Навчання моделюванню динамічних систем у середовищі MATLAB/Simulink.

## Зміст
У лабораторній роботі розглядається розв’язання звичайних диференційних рівнянь (ЗДР) першого порядку методом моделювання в середовищі Simulink. Для цього будується блок-схема, яка описує задачу Коші:
x'(t) + 2x(t) = sin(t),
x(0) = 0

Використовуються наступні блоки:
- **Integrator** — інтегрує похідну x'(t),
- **Sum**, **Gain** — формують праву частину рівняння,
- **Sine Wave** — джерело `sin(t)`,
- **Scope** — вивід графіка розв’язку.

## Перевірка результатів
Для перевірки отриманого в Simulink рішення будується графік розв’язку в MATLAB через функцію:

```matlab
function y = f(t)
    y = (1/5)*(sin(t) - 2*cos(t)) + (2/5)*exp(-2*t);
end

t = 0:0.1:2;
y = f(t);
plot(t, y);
grid on;
```
