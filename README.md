# Лабораторна робота №3  
**Моделювання клітинних автоматів**

## Мета
- Ознайомитися з принципами побудови клітинних автоматів.
- Дослідити правила еволюції клітинних автоматів.
- Ознайомитися з грою "Життя" Джона Конвея.
- Реалізувати клітинні автомати в MATLAB.
## Завдання
1. Вивчити теоретичні основи клітинних автоматів.
2. Ознайомитись із програмою **Life** у MATLAB.
3. Запустити та дослідити поведінку **Conway’s Game of Life**.
4. Для випадкової початкової конфігурації (50% ймовірність стану `1`) дослідити еволюцію для наступних правил:
   - **Правило 18**: `00010010`
   - **Правило 73**: `01001001`
   - **Правило 136**: `10001000`

## Реалізація
Програма реалізована у вигляді графічного інтерфейсу на MATLAB, що дозволяє запускати симуляцію клітинного автомата, зупиняти її або виходити з програми.

Ключові особливості реалізації:
- Ініціалізація випадкової конфігурації клітин (`rand < 0.5`)
- Візуалізація еволюції за допомогою `image(...)`
- Оновлення станів за класичними правилами Game of Life:
  - Клітина живе, якщо має 2 або 3 сусіди.
  - Нова клітина "оживає", якщо має рівно 3 сусіди.
